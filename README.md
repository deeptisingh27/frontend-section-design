# Mozilla Firefox Club - Frontend Section Design

## Task Overview  
This project is part of the **“Innovative Frontend Section Design”** task for the Mozilla Firefox Club website.  
It focuses on building an **engaging, responsive, and beginner-friendly** section using **HTML, CSS, and JavaScript**.

---

## Live Demo
**View the live project here:**  
[Click to Visit Demo](https://yourusername.github.io/mozilla-club-frontend/)


---

## Features
- **Attractive Hero Section** with gradient background and clean layout  
- **Animated Counters** to show community stats (Members, Events, Projects)  
- **Interactive Join Button** with a fun alert popup  
- **Responsive Design** that adapts to all screen sizes  
- **About Section** with 3 colorful cards (Learn, Build, Connect)  
- **Footer** that adds a personal touch

---

## Design Choices
- **Color Theme:** Mozilla-inspired orange (`#ea580c`) for energy and visibility  
- **Typography:** Clean and modern font (Poppins) for readability  
- **Layout:** Simple Flexbox-based layout for easy alignment  
- **Animation:** Lightweight JavaScript counter animation for engagement  
- **Responsiveness:** Media queries for mobile and tablet compatibility

---

## Technologies Used
- **HTML5** - Structure of the page  
- **CSS3** - Styling, colors, and responsive layout  
- **JavaScript** - Interactivity and simple animations
